# English

The base language: the [concept spine](README.md)'s terms *are* the English vocabulary, so this
file holds only what that table can't say.

## Conventions

- Sentence case throughout — titles, buttons, chips ("Recently deleted", not "Recently Deleted").
- American English ("Gas station", "Kilometers").

## Rivals and decisions

- A track is never a *route*, *path* or *trail*.
- *trip*, *journey* and *travel* are three concepts and stay three words — except the deafness
  notification, which says *trips* deliberately: what the user loses is the real-world trip, not a
  file.
- *restore* covers both restore-backup and restore-track; the object carries the difference
  ("Restore from backup" / "Restore track").
- *search* covers both search-text and search-gps; context separates them.
